# Shiny Kicks Marketplace

Plugins de contenido para Shiny Kicks en Claude Cowork.

## shiny-kicks-video
Editor de Reels/TikTok: pregunta el tema, propone un storyboard para autorizar y entrega el video 9:16 con textos animados, zooms, audio y copy.

**Instalar en Cowork:** Customize → Plugins → Add marketplace → pegar la URL de este repositorio → instalar "shiny-kicks-video".
**Usar:** sube tu video y escribe `/reel`.
